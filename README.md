# PodWiki

PodWiki 是一个使用 Markdown 构建的播客 Wiki，收录值得长期阅读的中文播客与视频访谈，并为每期节目保存可追溯的来源、结构化元数据、内容总结和带时间码逐字稿。

项目优先服务播客内容的发现与阅读：节目页提供单集索引，单集页记录来源与处理状态，独立的总结和逐字稿用于快速理解与深入检索。
