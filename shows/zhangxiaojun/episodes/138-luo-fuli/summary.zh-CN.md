# 罗福莉：Agent 时代如何重写模型、Infra 与组织

> 状态：`draft`。本文依据发布者简介和[完整 Qwen3-ASR 机器逐字稿](./transcript.zh-CN.md)整理，时间码来自当前正式机器稿。关键片段尚未逐段核听，专有名词、技术数字与行业判断尚未独立事实核查，不代表已完成人工审核。

## 一句话总结

罗福莉把 OpenClaw 带来的冲击概括为一次系统级范式变化：模型不再单独交付答案，而要与记忆、工具、上下文和多智能体框架共同完成长期任务；相应地，后训练、RL Infra、模型架构、算力分配和研发组织都需要围绕 Agent 重新设计。

## 为什么值得听

- 这不是一次只谈模型参数或榜单的访谈，而是把 Agent 框架、基础模型、后训练、推理成本和组织结构放进同一套因果链。
- 罗福莉从 MiMo-V2 系列研发和团队实践出发，给出了长上下文、混合注意力、模型规模、训练稳定性及算力比例等一线判断。
- 节目既讨论“AI 训练 AI”“两年 AGI”等激进预测，也保留了对多模态必要性、多人 Agent 上限和旧 benchmark 失真的不确定性，适合用来辨认行业共识与个人下注的边界。

| 交互框架 | 从聊天入口变成可执行的通用 Agent 框架 | 持续状态、工具调用与任务环境 |

### 1. OpenClaw 的意义不是多了一个聊天入口，而是出现了通用 Agent 框架

- **嘉宾主张**：真正的变化来自持久记忆、分层上下文、多模型路由、工具调用和可持续运行被组合为一个开放框架；用户交付的是目标，系统负责拆解并跨时间执行。
- **依据与经历**：罗福莉描述自己在几天内把它用于个人助理、团队管理和研究任务，并认为这类框架能让中等能力模型在大量工作上接近更强模型的实际效果。
- **边界**：效率提升和模型能力接近程度来自嘉宾个人体验，没有统一任务集或对照实验；顶尖模型仍决定能力上限。

### 2. Agent 能力来自模型与 Scaffold 的共同进化

- **嘉宾主张**：模型之外会形成一层越来越厚的 `scaffold`，用记忆、Skill、路由和反馈补足模型；框架又会反过来暴露模型短板，推动下一轮训练。
- **依据与经历**：团队把成员的任务模板和隐性经验沉淀为 Skill，并让不同人的探索在群体中扩散；她把这种人—Agent、Agent—Agent 的连接视为群体智能，而不仅是个人效率工具。
- **边界**：Skill 是否能稳定迁移、多人 Agent 是否能超过最强单模型，目前仍受评估质量、上下文组织和成本约束。

### 3. 从 Chat 到 Agent，后训练的对象从“回答”变成完整任务轨迹

- **嘉宾主张**：Chat 时代的字符串输入输出和单点 benchmark 不足以训练真正的 Agent；后训练需要高复杂度、长时程、可交互的真实环境，以及能够评价过程和结果的奖励系统。
- **依据与经历**：代码之所以重要，是因为它同时提供长链任务、可执行环境和相对清晰的验证信号；而百万级上下文的数据构造、环境复现和 reward 设计都会显著抬高成本。
- **边界**：节目给出的是研发方向和经验判断，没有披露可复现的数据集、奖励函数或消融结果。

### 4. RL Infra 必须从“模型 Rollout 引擎”改造成 Agent 中心的耦合系统

- **嘉宾主张**：Agent 训练会同时调用模型、工具、CPU、GPU、存储和外部环境，基础设施不能再只优化单一模型的吞吐；故障恢复、异构资源调度和框架兼容都成为训练本身的一部分。
- **依据与经历**：她认为，预训练需要提前半年到一年做架构下注，后训练则必须快速吸收最新框架和用户行为，因此研究、算法与系统基础设施要更紧密地共同迭代。
- **边界**：这部分是架构原则与趋势判断，节目没有提供 MiMo 内部 RL 系统的完整实现细节或性能数据。

### 5. 长上下文和成本效率必须在预训练架构阶段预埋

- **嘉宾主张**：Agent 会持续拉长上下文并增加调用次数，模型架构既要给后训练留出能力空间，也要降低长期推理成本；MiMo-V2 因此采用面向长上下文的混合注意力和 MTP 等设计。
- **依据与经历**：她讨论了注意力稀疏度、显存与计算瓶颈，以及不同规模模型对稀疏化的容忍度，并主张模型定价最终应更多反映产出价值，而非只按推理成本计算。

### 6. “1T 是入场券”背后，更关键的是研究冗余和训练可靠性

- **嘉宾主张**：她判断，要接近当时最强闭源模型，超过 1T 参数的高效基础模型是重要门槛；但正式训练算力不能吃掉全部预算，研究探索与后训练也必须获得足够资源。
- **依据与经历**：她给出的建议比例是研究、预训练、后训练约 `3:1:1`，并回顾 1T 训练中的 loss spike、专家不均衡和数值稳定性问题：即使 GPU 昂贵，也可能停训数天乃至数周排查。
- **边界**：参数门槛、算力比例以及不同团队的预训练/后训练投入均为嘉宾估计，不是公开审计后的行业统计；更大参数也不自动等于更强产品能力。

### 7. 多模态未必要求一个模型包办一切，Agent 可以协调专用模型

- **嘉宾主张**：视觉、语音、文本等能力可以由分别训练、成本和延迟更合适的专用模型承担，再由 Agent 统一调度；随着代码 Agent 降低多套 Infra 的维护成本，“为了工程整洁而统一”不再是充分理由。
- **依据与经历**：MiMo-V2 的 Pro、Omni、TTS 被她描述为同一 Agent 生态中的不同组件；她也观察到多模态模型似乎更具感知和“情商”，但承认传统 benchmark 未显示同等幅度的提升。
- **边界**：她明确表示不确定多模态是否是 AGI 的必要条件；关于感知能力提升的描述偏体验性，不能当作已验证结论。

### 8. 新范式需要流动、扁平并快速学习的研发组织

- **嘉宾主张**：在技术路线高速变化时，环境比既有经验更重要；组织应减少固定分组和职级权力，让数据、预训练、后训练和 Infra 人员围绕问题流动，并允许新人通过真实项目快速获得能力。
- **依据与经历**：她描述团队总体约百人、单代模型约二十至四十人，角色边界较弱，项目负责人不天然拥有行政权力；招聘更看基础、好奇心、热情和认知多样性。
- **边界**：人数、分工和管理效果来自嘉宾对自己团队的描述，未与组织名册或其他成员访谈交叉核验，也不必然适用于所有研发团队。

## 5 分钟读完

访谈的起点是 OpenClaw。罗福莉最初把它理解成模型外的一层 UI，但密集使用后改变了判断：持久记忆、上下文管理、模型路由、工具和时间触发共同构成了一个可扩展的 Agent 框架。它能接受高层目标、跨天推进任务，也能把一个人的方法沉淀为 Skill。模型依然设定能力上限，但框架决定能力能否稳定落到实际工作中。[00:01:31] [00:07:16] [00:17:41]

这种体验让“模型竞赛”的对象发生变化。过去的 Chat 产品以一次问答为中心，训练和评测也常把任务压缩为固定字符串；Agent 则要持续观察环境、选择工具、维护记忆并修正计划。代码率先显示这种变化，因为它既需要长上下文，也有可执行的验证环境。其他领域若想获得同样进展，就必须重建真实环境、设计可靠 reward，并评估一条完整轨迹，而不是只看最终几句话。[00:34:53] [00:35:32] [00:43:15] [00:46:15]

因此，后训练不再是预训练之后的一道轻量工序。罗福莉判断，头部团队的后训练算力可能逐渐接近预训练；研究探索本身还需要更大的冗余。她建议研究、预训练、后训练约按 `3:1:1` 分配，因为在超大规模训练中，loss spike、专家不均衡和基础设施问题都可能迫使团队停下昂贵训练，先找到真正原因。[01:46:03] [01:46:51] [01:47:38] [01:48:44]

Agent 也反向约束预训练架构。长期任务意味着上下文越来越长、模型调用越来越频繁，注意力、显存、计算量和推理价格都会成为产品边界。她用 MiMo-V2 的混合注意力、MTP 和多模型组合说明一种选择：基础模型先保留足够的能力上限，再让专用视觉、语音或生成模型被 Agent 调度，而不强求一个模型承担全部模态。[01:21:13] [01:25:18] [01:34:01] [02:14:38]

与之配套的 RL Infra 也要换中心。过去可以围绕模型服务器优化 rollout 吞吐，未来却要协调 Agent、工具、外部环境、CPU、GPU、存储和故障恢复。预训练的架构决策需要提前半年甚至一年，后训练又要迅速适应新框架和真实用户行为；系统、算法和数据团队因而无法继续按静态流水线分工。[02:29:42] [02:30:33] [02:32:50]

组织部分与技术判断高度一致。罗福莉描述的团队没有僵硬分组，预训练、数据和后训练成员会随问题流动，项目负责人也不靠行政权力推进工作。她更看重基础、好奇心、热情和差异化认知，并认为新人所处的环境往往比已有经验更能决定成长速度。Agent 又把个人经验沉淀为公共 Skill，组织学习和模型学习由此开始互相加强。[01:55:07] [01:59:24] [03:23:28] [03:24:46]

节目最后把这一框架放回三年 AI 演进史：ChatGPT 让预训练能力通过对话被激活，推理模型让代码和数学上的强化学习扩展，Agent 则把一次回答推进到复杂、长期、端到端任务。罗福莉把 2026 年视为“生产力变革之年”，并预测 AI 训练更强 AI 可能在一两年内出现、AGI 可能在两年左右到来；这些是高不确定性的个人预测，更适合作为她当前下注方向的说明，而不是确定时间表。[02:26:03] [02:26:49] [02:47:49] [03:05:09]
