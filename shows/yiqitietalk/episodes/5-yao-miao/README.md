## 发布者简介

> 今天的嘉宾姚妙，是中国顶尖越野跑运动员，亚洲首位在UTMB（环勃朗峰超级越野赛）不同组别三度夺冠的女选手（2018年CCC组、2024与2025年OCC组）。不仅如此，近两年，她在2023年夺得勃朗峰山地马拉松亚军，2025年蝉联上海马拉松中国籍女子季军，展现了“路野双修”的顶尖实力。
> 她的绝对实力背后是绝对热爱。她的伴侣看到她每次从山里回来眼里的光，毅然辞职支持她的运动事业。那么，这样一位传奇跑者的背后，有怎样的团队支撑？亮眼的成绩吸引来无数赞助商的橄榄枝，作为专业运动员怎样处理商业化带来的机会和挑战？光环加身以后，下一步该怎么跑？面对压力，她却说“我很轻松”。
